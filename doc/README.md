# Screenshots

PNG screenshots referenced by the package README live here. To generate
them, run the example app (`cd example && flutter run -d macos`), capture
your window, and save as:

- `screenshot.png` — overall showcase
- `screenshot_headings.png` — headings and lists view
- `screenshot_tables.png` — tables and code blocks view
- `screenshot_dark.png` — dark-themed view

Screenshots are not included in the published package (they're git-tracked
but excluded from the archive by pub), so add them here for the GitHub repo.
